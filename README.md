# design-patterns-course
## Patrones de Diseño: Soluciones prácticas y eficientes - DevTalles

### Installs
```ts
pnpm install -g deno
deno -v
```

### Run 🚀
```ts
deno 01-builder.ts

deno --watch 01-builder.ts
```

### Add dependences ✅
```ts
deno add jsr:@deno-library/logger
```
